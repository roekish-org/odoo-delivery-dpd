DPD France for Odoo 19: Predict, Relais, CLASSIC

Rate shipments, generate labels, track parcels and offer Pickup relay delivery from Odoo.

Features

RatingDelivery price computed from a DPD tariff grid (weight by zone) or from Odoo's native pricing rules. On the grid, a fuel surcharge (%) and fixed fees per parcel are added, and the volumetric weight (volume in cm³ divided by a divisor, 5000 at DPD) can replace the real weight when it is greater.
Delivery timeAnnounced delivery time in working days (minimum and maximum), set on the carrier and overridable per zone in the tariff grid. Returned with every quote and shown in the shipping wizard, so carriers can be compared on cost and speed.
LabelsDPD label generation through roulier on the e-Station web service (production or test environment), with the parcel number stored on the delivery order. PDF, PDF A6, ZPL or PNG.
TrackingA DPD tracking link is exposed to the customer.
Pickup relaysSearch nearby relays (Pickup MyPudo web service) and select one on the quotation or the delivery order, propagated on confirmation and sent on the label. The search key is optional: without it, type the relay ID directly.
ProductsDPD CLASSIC, DPD Predict (SMS time slot) and DPD Relais. CLASSIC and Relais parcels can notify the recipient by SMS or email; Predict always uses the Predict SMS.

Carriers and zones

Three ready-to-use carriers ship with indicative 2026 rates as editable demo data. DPD France publishes no public rate card: rates are negotiated per contract, so replace the demo grids with yours.

Security

  • e-Station credentials and the Pickup search key are restricted to the DPD Administrator group, and secrets are masked in error messages.
  • Fine-grained access rights with dedicated User and Administrator groups.
  • Multi-company isolation on the tariff grids.

Requirements

The module builds on Odoo's native delivery framework. Rating and relay search work with no external library. Label generation uses roulier, optional and imported on demand.

Deploy the module on the addons_path (Odoo.sh or On-Premise). The Apps > Import Module zip upload is data-only and cannot install a module that ships Python models. On Odoo Online (SaaS) Python libraries cannot be installed either, so label generation needs Odoo.sh or On-Premise, where roulier is available.
